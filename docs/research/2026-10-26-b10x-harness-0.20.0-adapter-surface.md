## Why it moved

Harness 0.20.0 adds `run --approve caller`, the L1 half of atlas ADR 0104 point 3 ("L1 enforces and
does not decide"). metaharness can only use it at a pin that has it.

## Not verified on 0.20.0

- **No live loop run.** Every run above was against the emulator; a paid one-turn run was not made.
- **An unanswered call.** metaharness's 25000 ms deadline denial was not run on the b10x adapter;
  it is the shared control-seam deadline the vendor adapters exercise.
- **`replace`.** The caller grammar has no rewrite, so a metaharness `replace` is written as a deny;
  how a rewrite reaches L1 is ADR 0104's open question.
- **The secret store under the floor**, as on 0.18.0 and 0.19.0.
