# Pi 0.80.3 adapter surface

Status: verified locally from the resolved `pi --version` and `pi --help` on 2026-08-31,
except where labelled unknown. This is a contract-first record, not a claim that metaharness can
run Pi.

## Verified launch facts

- The banner is exactly `0.80.3`.
- `--mode json` requests JSON output and `--print` makes the run non-interactive.
- `--no-session` suppresses session persistence; `--session-dir` otherwise names it.
- `--no-extensions`, `--no-skills`, `--no-prompt-templates`, `--no-themes` and
  `--no-context-files` disable the corresponding ambient discoveries. `--no-approve` ignores
  project-local files for the run. `--offline` disables startup network operations.
- `--tools` is a comma-separated allowlist. The built-ins named by help are `read`, `bash`,
  `edit`, `write`, `grep`, `find` and `ls`; `grep`, `find` and `ls` are read-only and off by
  default. The C1 baseline therefore asks for exactly `read,grep,find,ls`.
- `PI_CODING_AGENT_DIR` is the config root and `PI_CODING_AGENT_SESSION_DIR` the session root.
  The baseline places both in scratch and passes no `HOME`.
- `--api-key` exists, but a credential in argv is not an acceptable custody mechanism. The help
  also lists ambient provider variables. The baseline supplies neither; a runtime adapter must
  add explicit custody without logging or inheriting one.

## Contract state

`metaharness-pi` fills C1 with a byte-exact read-only launch fixture and reconciles the observed
banner with the `0.80.3` pin. It deliberately leaves two `ContractObligations` rows as gaps:

- no model-backed `--mode json` output has been captured and mapped to `metaharness.event/1`;
- extensions exist, but no blocking per-call input/response contract has been recorded or driven.

Until both close, Pi is absent from `Kind`, the CLI, doctor and capabilities. That absence is the
admission gate working.

## Next probes

1. Capture `--mode json --print --no-session` against a deterministic endpoint or a bounded live
   request, retaining the raw version-bearing stream.
2. Establish whether an extension can block one built-in call synchronously and record its exact
   input and response bytes. If it can only observe, the adapter must say so and cannot deliver the
   call-decision tier.
3. Determine a credential channel that is explicit and per-spawn without putting the secret in
   argv or inheriting provider variables.
4. Only then add `Kind::Pi`; the compiler will force dispatch, doctor, capability and contract
   answers together.
