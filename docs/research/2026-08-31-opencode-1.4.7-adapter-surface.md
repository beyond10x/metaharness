# OpenCode 1.4.7 adapter surface

Status: verified locally from the resolved `opencode --version`, `opencode --help` and
`opencode run --help` on 2026-08-31, except where labelled unknown. This is a contract-first record, not a
claim that metaharness can run OpenCode.

## Verified launch facts

- The banner is exactly `1.4.7`.
- `opencode run ... --format json` requests raw JSON events; `--dir` names the working directory.
- `--pure` runs without external plugins. The global command also exposes MCP, agents and plugin
  installation, so pure mode is an essential baseline rather than a cosmetic flag.
- `--model` takes `provider/model`. `--thinking` controls whether thinking blocks are shown.
- `--dangerously-skip-permissions` auto-approves permissions not explicitly denied. The baseline
  never passes it.
- `--attach` and the server commands exist; the baseline starts neither and binds no port.
- The help exposes no tool allowlist and no per-call hook flag. Permission and plugin mechanisms
  may exist in configuration, but their bytes and blocking semantics are unknown until recorded.
- The C1 baseline places XDG config, data and cache roots in scratch and passes no `HOME` or
  credential variable.

## Contract state

`metaharness-opencode` fills C1 with a byte-exact pure JSON launch fixture and reconciles the
observed banner with the `1.4.7` pin. It leaves two rows as explicit gaps:

- no model-backed `run --format json` stream has been captured and mapped;
- no blocking permission/plugin call seam has been recorded and driven.

OpenCode therefore remains absent from `Kind`, the CLI, doctor and capabilities. `--pure` proves
only that external plugins were disabled; it proves neither tool restriction nor a control seam.

## Next probes

1. Capture the JSON stream with one text turn and one tool call, preserving every unknown event.
2. Inspect a scratch configuration produced by the binary itself and test one explicit deny. The
   vendor record must show the call blocked before any tier is declared delivered.
3. Establish explicit credential custody and whether the local server can be disabled completely
   during a one-shot run.
4. Add `Kind::OpenCode` only after the recorded-wire and hook-input obligations are filled.
